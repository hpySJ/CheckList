# checklist-site v2.0.0

## Render 설정

- Build Command: `npm install`
- Start Command: `npm start`
- Environment Variables:
  - `SUPABASE_URL`
  - `SUPABASE_KEY`

## Supabase SQL

Supabase SQL Editor에서 `supabase.sql` 내용을 실행하세요.

## 배포 확인

Render 로그에 아래 문구가 보여야 새 버전입니다.

```text
✅ checklist-site version 2.0.0 starting
✅ Node version: v20...
```

아직 `checklist-site@1.0.1` 또는 `Node.js v26.1.0`이 보이면, GitHub에 옛 파일이 남아 있거나 Render 캐시가 남은 것입니다.
